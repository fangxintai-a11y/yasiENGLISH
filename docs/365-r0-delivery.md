## 复核方式

1. 阅读四科样本，先做题，再看文末答案与示例；听力可播放或下载WAV。
2. 查看规则说明中的四种预算，确认180分钟模拟不会叠加普通日任务；9/9/6/7和四项AI估分为8均不能确认项目最终达成。
3. 运行 `npm run check:curriculum`，库存和样本状态应与上表一致。
4. 查看数据契约，确认后续Task 1评分键、逐题错因、评阅者和完整测评证据等字段尚待对应阶段扩展，不能直接塞入P1白名单外。

音频已完成格式、非静音、模型校验与帧级时间检查，尚未人工审听；四份内容均为自编draft，尚未独立教师审校。重新生成音频时应核对材料版本、时长与证据时码，再运行校验，不能只替换文件。
