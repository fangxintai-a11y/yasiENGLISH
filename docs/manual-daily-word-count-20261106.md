# 每日新词与加学数量自选

本阶段基于连续默写提交`7d91028bd`，分支`codex/manual-word-count-20261106`。只调整新词数量的计划逻辑、首页和相关设置，不部署生产。

## 规则

- 每日新词始终取原有`settings.dailyNew`，可设0–100个，0表示当天只安排复习；不随考试日期、考前冲刺、考后状态、学习时长或复习积压而自动改小或暂停。
- 今日待学新词 = 每日目标减去今天已学的新词，最低为0；由现有选词函数过滤已学词、优先导入词和目标词，词库不足时取实际剩余数量。
- 到期复习仍按原优先级与时间预算安排；新词数量不会因此减少，总预计时长可能超过时间预算。记忆曲线、首次评分和学习记录算法不变。
- 考试日期继续用于倒计时、记忆预测和复习加密；预测按自定每日数量计算，不再假定冲刺期停止学新词。
- 额外加学每轮自选1–100个，支持快捷选择与自定义；不改变每日目标。引擎对无效数量返回空轮次，不回落为默认每日计划。
- 已有学习轮次保持不变；目标改大后，完成当前轮次再按新目标补足；改小不会撤销已学词或删除进度。

## 页面

首页顶部增加“每日新词目标”，显示每天数量、今天已学和计划内可学数量。“调整每日数量”打开选择器，保存才生效，取消保留原设置。

当天计划完成后，原“再认识5个新词”替换为“继续学新词·自选数量”。每日新词已达目标但仍有复习时，也保留加学入口；当前学习轮次进行中时优先继续该轮。词库不足会显示实际数量，新词学完时禁用空轮次入口。

“我的→学习设置”使用同一个每日数量组件；雅思计划、考试设置、关于与引导文字同步说明新规则。首页弹窗放在入场动画容器外，避免固定定位落到整页高度中间、屏幕上看不到。

## 数据

复用既有dailyNew字段及账号快照同步，没有新增数据库字段、修改服务器、导入生产数据或清理学习记录。加学数量只用于这一次轮次，正常进入原有学习和复习记录。
