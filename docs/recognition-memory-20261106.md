# 认识／不认识／不太记得：真实记忆排程

本阶段基于`88429fdd8`，分支`codex/recognition-memory-20261106`。用户确认三档回忆反馈影响复习周期，并补充要求前端质量不能降低。本阶段只开发并提交候选分支，不部署生产。

## 交互

- 正常背新词及之后的词义识别复习统一采用三档反馈，替换“我早就会了”“想好了，看答案”“看完了，下一个”。
- 先展示英文及可选英文语境，主动回忆后点击“查看释义”。释义在揭晓前不进入提示区DOM，揭晓后可读释义、例句、记忆提示及原有图片提示。
- 揭晓后选择“认识”“不认识”“不太记得”，每个按钮显示约下次复习间隔。认识=能想起主要意思；不太记得=费力但最终想起；看答案才想起、完全想不起或认错归不认识。
- 保留新词“先猜后看”的既有偏好；到期识别复习始终先隐藏释义。Space/Enter揭晓，1/2/3选择对应反馈；不默认用Enter提交“认识”。
- 听写、产出及专项客观题仍根据实际答案评分，独立默写功能保持原样。

## 调度

沿用项目已有ts-fsrs及记忆稳定性、难度、复习次数、遗忘次数和到期时间，不另写固定天数表。三档分别映射Good、Again、Hard，继续使用现有目标记忆率及考前复习加密设置。

新词采用既有1分钟/10分钟学习步骤：初次“不认识”约1分钟，“不太记得”约6分钟，“认识”约10分钟确认。短期确认成功后进入按天计算的复习，再随表现延长；熟词遗忘会缩短并进入重新学习。按钮间隔为近似值，长期排程保留既有随机分散机制。

删除原来“我早就会了”直接伪设为摸底已知词并随机延后10–30天的路径。正常新词不再强制接原有同轮识别选择题；旧未完成轮次只在该词实际被评级后移除其后续重复识别题，听写/产出任务保留。

每次真实评级更新对应阅读识别卡。首次遇见的词无论哪一档只计一次当天新词；之后到期重现只计复习，不重复计新词，首答历史保留。再次忘记会进入原错词本；单词识别反馈不制造拼写错误记录。

轮次内，在当前题完成的边界插入本轮已评级且真正到期的词，不中途打断、不等待计时，也不把无关积压全塞进来。首页每15秒及重新获得焦点时重算到期任务，短周期复习不要求手动刷新页面。

## 样式检查

用户截图指出的发音按钮拉伸和三档文字溢出已修复。发音控件为44px；三档按钮使用自适应高度与独立行，文字、间隔和提示完整容纳。内容区可滚动，揭晓与评级操作区保持独立，不覆盖长例句或释义；揭晓后自动定位到词条和释义。英文重点词沿用项目主题高亮。

验收覆盖320×568、390×844、768×900、1280×900，浅色和深色，长例句及揭晓前后。断言包括页面宽度、每个按钮子元素边界、发音控件高度、操作区不覆盖内容、评级按钮中心实际可点击。截图等待页面入场动画结束，保存在本机忽略目录`local-content/recognition-*.png`。手机证据为Chrome模拟视口，不宣称真实iPhone验收。
