# 跟读生词进入优先学习

## 使用方式

跟读原文中的词可以点击。弹窗展示词库原形和释义，确认“不认识，加入优先学习”后，原文以点线标记。重复点击不会重复入池，也可撤销。首页、跟读首页和本轮总结都有“学习待学词”，每轮可自选1–100个，今日新词目标为0或已经完成时仍可主动学习。

新词排在普通新词之前，遵守每日自定额度；学过但忘记的词进入优先复习，无需等到原定到期日。已有未完成轮次时，选中的词接在当前题之后，保留当前题、作答反馈及其他任务。专项练习不会被直接覆盖。

支持已有词库内的词形匹配，例如huts对应hut；有歧义时显示候选并由学习者确认。没有收录的词会明确提示，可搜索原形，不会假称已保存或生成不存在的学习卡。

## 数据边界

沿用既有queue字段和账号SQLite快照同步，不新增服务端字段或数据库迁移。新词使用原始ID，已学词的明确再学请求使用review:ID，避免把旧导入队列里已经学习的词突然全部恢复为待学。

加入待学池仅改变队列，不改变FSRS卡、每日计数、听写/产出轨、录音或当前学习轮次。实际完成认知学习时移出队列，再按认识/不认识/不太记得更新原FSRS状态。跨设备同步包含加入、撤销及消费，不同步录音。

隐藏原文的说话阶段不增加可点词；用户主动偷看后才显示。录音及申请麦克风期间禁用点词。弹窗快捷键不会触发背后的句子操作；关闭后继续原阶段。
