# 连续默写：本阶段交付

## 范围

基于已发布词汇版 `1afd02640` 及发布记录 `fa94bb5c6`，在独立工作区和分支 `codex/typing-experience-20261106` 开发。用户明确要求完全默写：只给中文或发音，不能照着英文抄写。本阶段只调整打字输入与作答流程；不加入365计划或每日六科模块。

参考本机 Qwerty Learner `1182426f2bd0a28c95302c33f9e19136b1262a70` 的输入响应、连续切词、快捷重听、音效缓存和下一词发音预载。参考项目是GPLv3；本次使用现有React、原生输入框、项目已有音效独立实现，没有复制其源码、音效、图片或加入其依赖。

## 学习行为

- `#/spelling`：中文默写或单词听写，继续支持词源选择和1–100词。默认连续默写，拼对自动下一词；也可关闭连续模式，逐词确认。
- `#/practice`：单词默写、句子默写、句子听写。原先展示英文的抄写模式改为中文或音频出题；纯句子听写提交前也不显示中文翻译。
- 正常复习中的拼写、产出、听写共用新输入框。产出题不再自动给首字母。
- 作答前不渲染英文例句、词形、字母槽、词长或逐字对错。输入框只显示本人输入，使用正常光标、选择和退格；字符准确率也不在输入过程中显示。
- 拼错按Enter或确认后，才展示正确拼写与错字反馈，再按Enter继续。不会自动清空错误，也不要求照着正确答案抄一遍才能继续。主动查看答案算未答对。
- 连续切词保留同一个原生输入框与焦点，没有原先的260毫秒延时。错题反馈期间保留首答，不重复计分。
- 继续接受英美拼写。`program/programme`、`catalog/catalogue`等具有前缀关系的异体，短形式用Enter确认，避免正在输入长形式时提前切题。
- Ctrl/⌘ J重听（仅有音频入口的输入框），Esc离开输入框；输入法组词期间不提交，中文输入给出切换提示。粘贴答案被阻止。
- 使用原有音效开关；预载后两项发音，内存预备池最多四条，预载不会播放。手机视口变化时将原生输入框滚到可见位置；默写练习隐藏底部导航。

## 数据边界

独立拼写仍只写既有错词本与拼写诊断，沿用账号快照同步；正确答题不改记忆排程。`cards`、`skills`、`days`、未完成的复习`session`保持不变。

打字练习仍只在整轮结束后写一条原有`typing`记录。正式复习仍由原有评分和排程函数记账：主动看答案记“重来”；首答错误不能通过随后继续操作改成正确。

没有修改服务器、数据库结构、登录鉴权、同步协议、依赖或发布脚本。媒体仍在本机忽略目录，没有将MP3/PDF重新加入Git。生产服务器和用户生产数据未操作。
