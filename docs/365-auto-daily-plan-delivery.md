# 今天开始、自动材料与四科随时练

本阶段基线：`f939895af`。开发分支：`codex/ielts-365-auto-daily-plan`。

## 已实现

- 新计划默认今天，任意日期都能开始，不必等周一。每7个训练日推进原课程周期，课程预算仍为120分钟；目标仍是正式总分≥8、听读各≥8.5、写说各≥7.5。
- 尚未开始的未来计划可以点“从今天开始，自动安排”。保存同ID的新修订，保留历史；已有课程成果时拒绝重排。明确标记为自主练习、没有课程day的成果可以保留，不妨碍开启课程。
- 首页显示“今天先做”和“开始下一项任务”，课程卡直接列出平台安排的材料并进入对应工作台。听读题、Task 1/2、口语Part 1/2/3都使用精确ID、版本和哈希。
- 写作按课时自动安排段落、Task 2或Task 1+2；口语按课程范围自动安排各Part。未交草稿、已有作品、已开始的听读作答优先恢复原题，不因题库排序变化换题。
- 课程的独立检查题与普通练习题分开预留；基线和后续检查节点按现有课程生成。前14天阅读先题型热身，再进入原定完整主练，原整套计时不缩短。
- 首页顶部有四科快捷入口。无task的通用入口和显式`mode=practice`入口都是自主练习：无计划时自动准备今日计划，已有未来或过期计划不修改；四科不因当天没排课、开始日期未到或365天已结束而锁住。
- 自主练习先自动选未做practice题，耗尽后明确标记原题复习，不动用独立检查池充数。自主作品保存实际日期，不生成课程mission；听读自主记录不附课程day，写说仅在有效范围内保存日次信息，任务ID与课程隔离。
- 从旧作品开始新自主练习使用今天日期，原作品日期和修订不改。跨账号读取、异步保存与同账号重新登录期间的旧操作都设有隔离检查。
- 今天没有词汇课程时，仍可自选1–100个词加练；复习和新词记忆继续存入原有词汇记录。

## 与IELTS Lab的本阶段连接

`#/ielts`展示同一365计划的当前阶段与课内词汇预算，提供返回今日课程、词汇和四科订正的入口。原“考试计划”标签改为“词汇排程”，说明它负责词汇记忆调度。

以下是当前事实，不能混为一谈：

| 模块 | 当前作用 | 记录边界 |
| --- | --- | --- |
| 365课程 | 推荐每天的课程顺序与具体材料 | 作答和必要复盘完成后保存对应课程进度 |
| 自主四科 | 随时练习，自动选材 | 保存作品与作答，不冒充当天课程完成 |
| 词汇新学、复习、加练 | 使用同一个词库和FSRS记忆记录 | 记忆记录正常保存；加练数量由学习者选 |
| IELTS Lab | 拼写、同义替换、易混词、闪测、取词、错词阅读、造句 | 沿用原有专项逻辑，不当成雅思分数或四科完成 |

下一阶段的建议，**本阶段尚未实现**：

1. 把“题中生词→词汇复习→对应专项→回到四科新题验证”接成完整闭环，保存来源作品、原句与错因。
2. 根据真实错因自动推荐专项：拼错进入听写，改写没认出进入同义替换，会认不会用进入造句；用户仍可随时练任意科目。
3. 专项使用当天已有词汇/复盘时间，不叠加一份强制课表；自主加练时间另记。
4. 统一展示365训练目标日与正式考试日期的区别。未报名时不得把训练结束日伪称真实考试日期。
5. 为专项增加独立成果记录和复测证据，再决定哪些客观结果可以更新对应记忆轨道；不直接把旧practice标记全部改为FSRS评定。

## 材料与存储边界

平台自动读取本机已导入题库、现有`/local-bank/`目录，以及可用的私有题源。此次没有重启抓取、编造真题或上传录音。分配器只计算预留，不伪造作答或成绩。

**现有材料不足以填满全年全部未见题与独立检查。** 缺口会显示待补齐，不能拿旧题、缺图Task 1或practice题伪装未见测评。已分配的未开始未来课程可随真实库存、成果和已接受的弱项建议调整；已开始的原题保持。

学习记录继续使用现有本机存储与服务器SQLite同步通路，没有新增后端schema。Git中MP3/M4A/PDF数量仍为0，私有题目和本地测试产物不提交。
