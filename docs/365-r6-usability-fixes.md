# R6 本地复核后的使用问题修复

2026-11-05，基于 `v365-rc1`，在 `codex/ielts-365-r6-prestart-fix` 修复用户本地复核发现的问题。原候选标签不移动，未部署、未合并 main。

## 听读入口与真实题库

- 计划从11月9日开始、当前为11月5日时，听力和阅读共享页面在渲染中计算周索引，抛“评阅作品日期早于计划开始日”，造成白屏。开始前改用空选材偏好，保留真人评阅日期校验和限时首答的开始日期限制；订正页同类分支也修复。
- 真实704条原材料与32个派生整套的选材反复归一化全文，全量检查约19.72秒。只缓存材料当前精确原文的归一化结果，原地修改正文会失效；不缓存资格判断、账号记录或可变题库数组。冷检查降至约190毫秒，完整456,591字节判断/选材结果前后相同（SHA256 `5bbe7f6f47d2d09dfb143b01fdbe80e6b4556c1bea1a6b68b2bfceebb732dfd3`）。
- 首次并发导入会出现一条加载704条成功、另一条因重复写事务失败而显示2条样例；同账号改为共享仅在途的加载，完成或失败即清除。实测4次全新隔离上下文均返回704/704，手动导入后重新加载、账号隔离及失败恢复也通过。
- 首次并发准备音频也能复现一成功一失败，而本机已保存正确SHA的9MB音频。音频准备改为共享仅在途的Blob加载任务，每次调用各自生成和释放播放URL，避免相互撤销。3次隔离实测均只下载一次，释放第一个URL后第二个仍能读出459.5491秒时长，无媒体错误。

## 数量与手机输入

- 新用户每日新词默认20；既有设置保留。每日数量支持0–100整数，0为只复习，非法输入不保存。设有考试日时也尊重这个上限，原分钟、复习积压和冲刺限制保留。
- 完成当日词汇后，本次加练支持1–100个，保留10/20/30快捷选择，替代固定5个。20个只是建议起点，实际安排还受已有课表、复习和时间限制影响；[雅思官方评分说明](https://ielts.org/take-a-test/preparation-resources/writing-test-resources)强调词汇使用的准确性与灵活性，没有每天固定背词量即可达8分的规则。
- 手机听写、拼写和词汇产出输入区上移；只在输入已聚焦且可视区域缩小时调整滚动，不额外自动聚焦。390像素宽、模拟键盘后420像素可视高度的检查覆盖实际可见字母及按钮，不能当作真实iPhone软键盘已验收。
- 首页显示“四科练习入口”，四科链接与学习记录分组。计划开始前明确显示准备事项和开始日期，不再让用户找不存在的“今天四科清单”。不修改开始日期、365天课表或120分钟预算。
