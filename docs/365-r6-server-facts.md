## 目录与容量

`/srv/yasi`是系统盘上的普通目录，不格式化、不挂载磁盘。应用保留current与previous两版；共享图集/词汇音频一份，私有材料、SQLite与备份独立于应用目录。额外非atlas音频保留原URL，放共享图集的`_public/`子目录，接收器按受控清单创建链接。

任务书预算为两份应用约0.1GB、共享图集约0.84GB、压缩听力约0.8GB、数据库及14份备份约0.1GB，总约1.9GB。实际应用/共享资产和自写转码夹具的测量写入交付记录；完整32套私有转码由资料AI在Mac执行，其实际产物容量与上线后剩余空间待测，不能把预算当实测。上传前与部署后均要求根盘剩余至少3GB。

可选1GB swap没有获用户同意，本候选不创建、不启用、不写`fstab`。默认Python API+Caddy运行方案不依赖服务器Node构建。
