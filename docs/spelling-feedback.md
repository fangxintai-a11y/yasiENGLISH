# 拼写核对后回顾词条

独立拼写的“连续默写”改为“自动核对”：默认输入完整且正确时自动判定，但不自动切题；关闭后按Enter或确认按钮核对。答对、答错、主动查看答案都先停留在本词，包括最后一词。显示标准拼写、错误诊断、英美音标、全部词性与中文释义、已有中英例句及使用备注；无例句如实提示。点击下一词或按Enter后继续，最后一词手动查看本轮结果。

打字练习中的单词默写、整句默写和听写同样保留核对结果，手动继续。正式复习原有确认步骤保留，手机上也展示中英例句。作答前仍为完全默写，不显示答案、首字母、字母数或逐字对错；发音按钮及两词预加载保留。

桌面输入框持续挂载、键盘Enter继续后清空并保持输入焦点；触屏核对后移开输入焦点、滚动到反馈，方便收起键盘阅读。读词条的时间不计入打字输入时间；不重复计分、不重复保存错词，也不重写正在进行的复习轮次。

`scripts/test-spelling-e2e.mjs`覆盖正确、错误、主动揭晓、末词停留、音标与中英词义例句、IME提交、重复Enter、两设备错词同步和各记忆轨不被重复修改。使用实际构建、临时SQLite和隔离账号；UI检查320/390/768/1280px、深浅主题、横向溢出和继续按钮实际命中，缩小可视高度检验输入位置。截图保存在忽略目录，未将模拟视口称为真实iPhone软键盘验收。

本次随逐词摸底及不会词优先版本一起发布。发布继续采用本地干净构建、GitHub提交、校验制品上传、服务器一致性备份、切换代码与实际HTTPS验收；沿用现有账号和SQLite，不恢复旧数据库覆盖已有进度。
