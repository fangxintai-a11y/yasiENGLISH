# P1 独立学习数据通路交付记录

日期：2026年11月3日。阶段分支：`codex/ielts-365-p1-data`。本阶段在开发与隔离验证完成后提交GitHub，等待用户复核，不自动进入后续阶段。

项目目标固定为学习365天后取得雅思总分8.0及以上，每项至少6.5，每天投入2至3小时。7与7.5作为中间里程碑。当前阶段完成的是支撑该训练的数据库和同步基础，并非全年训练界面或学习目标达成。

## 已完成范围

- SQLite独立学习记录、不可变修订、删除标记、幂等收据与模块迁移表，沿用已有账号。
- 独立学习API和能力检查，按账号隔离；旧词汇快照保持原通路。
- IndexedDB保存记录和outbox，离线/响应丢失后恢复上传，按服务端游标拉取变更。
- 同一作品并发修改保留冲突副本，解决后形成新修订；反馈引用准确原稿修订和hash。
- 访客成果需明确选择才并入账号，换账号不上传前一账号的待同步内容。
- 录音Blob按账号与词库存本机，文字和元数据可同步；另一设备不会假装拥有原录音。
- `server/runtime-files.json`及部署接收器完整打包API运行模块，缺模块阻止切换。
- 统一365天8分目标、成绩来源与达标规则的开发计划，明确每阶段commit、push、核对远端SHA后停止。
